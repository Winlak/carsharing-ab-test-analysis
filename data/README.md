# Данные

В репозитории нет данных реального каршеринга. Все файлы в `data/generated/`
создаются детерминированно командой `make data` и намеренно исключены из Git.

Генератор создаёт три согласованных источника:

- `users.csv` — признаки пользователя, известные до назначения варианта;
- `assignments.csv` — назначение в контроль или treatment;
- `events.csv` — события экрана бронирования, показа подсказки, бронирования и отмены.

Лицензия на код и сгенерированные данные — [MIT](../LICENSE). Данные являются
синтетическими и не описывают клиентов, поездки или результаты какого-либо
реального оператора каршеринга.
