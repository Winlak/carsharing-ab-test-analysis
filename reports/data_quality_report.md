# Проверка качества данных

Все источники синтетические, сгенерированы детерминированно. Гранулярность
витрины — один назначенный и созревший для наблюдения пользователь.

| Проверка | Факт | Ожидание | Статус |
| --- | ---: | ---: | --- |
| Одна запись назначения на пользователя | 0 | 0 | pass |
| Пересечение вариантов по пользователю | 0 | 0 | pass |
| Дубликаты event_id | 0 | 0 | pass |
| Полные дубликаты событий | 0 | 0 | pass |
| События без назначения | 0 | 0 | pass |
| События до назначения | 0 | 0 | pass |
| Показ подсказки в control | 0 | 0 | pass |
| Покрытие пользователей при JOIN assignments → users | 0 | 0 | pass |
| Дубликаты user_id в SQL-витрине | 0 | 0 | pass |
| Потеря пользователей между assignment и mature cohort | 0 | 0 | pass |
| Отмена без созданного бронирования | 0 | 0 | pass |

**Интерпретация.** Проверки исключают смешение групп, дублирование событий,
потери на ключевом JOIN и явные временные нарушения. Для реального запуска к
ним следует добавить мониторинг задержки событий и сверку с продовой схемой.
